# Kiln Optimization ML Model: Nickel Ore Extraction

## Overview
This project features a machine learning model and an interactive web application designed to optimize the rotary kiln metal extraction process. Built primarily with Python and deployed via Streamlit, the application evaluates extraction efficiency using domain-specific mathematical formulas and predictive analytics.

## Tech Stack
* **Language:** Python
* **Data Processing & Model Training:** NumPy, Jupyter Notebooks
* **Visualization:** Matplotlib
* **Deployment Interface:** Streamlit

## Key Features
* **Mathematical Data Synthesis:** Utilizes metallurgical formulas within Jupyter Notebooks to construct and simulate reliable training datasets representing the kiln environment.
* **Predictive Modeling:** Evaluates key operational parameters to predict extraction efficiency and identify optimal processing conditions.
* **Interactive Web Interface:** A user-friendly Streamlit dashboard that allows users to input process parameters and instantly visualize extraction outcomes and trends.
